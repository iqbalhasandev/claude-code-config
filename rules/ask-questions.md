# Asking Questions — Interview Tool, 4 Options, Recommendation First

Applies to every project and every session, including brainstorming skills that say to ask open questions.

- Every question to the user goes through the AskUserQuestion tool. Never ask a question as plain chat text
  and wait for a typed answer.
- Give 4 options (3 only when a fourth would be filler). Put the recommended option first and add
  "(Recommended)" to its label.
- Each option's description states its trade-off in one short line.
- Put up to 4 independent questions in one call.
- Short context the user needs to choose goes in chat text right before the tool call, not instead of it.

Reason: the user picks an option or writes their own faster than they answer a free-text question.
